商品卡片是前端日常很容易遇到的工作項目。實際切版時，最麻煩的通常不是排成幾欄，而是內容長度很難控制。商品名稱可能只有一行，也可能長到兩三行；介紹文字有長有短，有些卡片還會多出標籤或促銷資訊。

同一排的卡片就算已經等高，內部也不一定整齊。標題高度不同，中間內容的起點就會錯開，底部連結也可能停在不同位置。固定高度或限制文字行數雖然能暫時排整齊，內容一變就得重新調整。

Flexbox 可以把連結推到卡片底部，但每張卡片只會處理自己的空間。CSS Subgrid 則能讓不同卡片共用父層 Grid 的軌道，把標題、中間內容與連結區域一起對齊。

> [本文範例程式碼：blog-labs](https://github.com/LING-JUN-HAO/blog-labs/tree/main/subgrid)

## 巢狀 Grid 為什麼對不齊？

先看下面這個排版：上排有四格，依序放名稱、專案名稱、預計完成日期和日期；下排則是設計階段與開發階段。

上排兩個標籤欄的寬度會跟著文字變化，另外兩欄則占 `2fr` 與 `1fr`，所以四格不會等寬。

```html
<div class="layout">
  <div>名稱</div>
  <div>個人網站改版</div>
  <div>預計完成日期</div>
  <div>12 月 31 日</div>

  <div class="nested">
    <div>設計階段</div>
    <div>開發階段</div>
  </div>
</div>
```

```css
.layout {
  display: grid;
  grid-template-columns: max-content 2fr max-content 1fr;
  gap: 1rem;
}

.nested {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: repeat(2, 1fr);
  gap: 1rem;
}
```

![一般巢狀 Grid 的子層重新均分兩欄，分隔線落在整體寬度中間，偏離父層第 2、3 欄之間的格線](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794832014/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/basic-nested-grid.png)

下排的 `.nested` 雖然橫跨上排四欄，裡面卻重新分成兩個等寬欄位。下排的分隔線會落在正中間，對不上上排第二、三格之間的分隔線。就算兩層用了相同的 `gap`，位置也不會自動一致。

把 `.nested` 的欄軌道改成 `subgrid`，就能和父層共用格線。

```css
.nested {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;
}

.nested > * {
  grid-column: span 2;
}
```

![使用 Subgrid 後，兩個子項目各跨兩條父層軌道，分隔線與父層第 2、3 欄之間的格線對齊](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794832016/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/basic-subgrid.png)

改成 `subgrid` 後，`.nested` 會沿用上排四格的位置與間距。兩個子項目各跨兩格，上下兩排的分隔線就會落在同一處。之後不管標籤文字或容器寬度怎麼變，下排都會跟著調整，不必另外同步寬度。

前面是在對齊左右格線，商品卡片則要對齊上下區塊。做法一樣：讓標題、內容與連結沿用父層軌道。

## 三張內容長度不同的卡片

![外層 Grid 排成三欄，三張卡片等高，但連結區域沒有貼齊底部，下方留下空白](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794815419/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/cards.png)

```html
<div class="cards">
  <!-- 卡片 1 -->
  <article class="card">
    <h2 class="card__title">入門方案</h2>
    <p class="card__content">
      適合剛開始建立個人網站的使用者。
    </p>
    <footer class="card__footer">
      <a href="#">查看方案</a>
    </footer>
  </article>

  <!-- 卡片 2 -->
  <article class="card">
    <h2 class="card__title">適合多人協作與內容管理的進階方案</h2>
    <p class="card__content">
      提供權限管理、版本記錄與更多儲存空間，適合需要一起維護內容的團隊。
    </p>
    <footer class="card__footer">
      <a href="#">查看方案</a>
    </footer>
  </article>

  <!-- 卡片 3 -->
  <article class="card">
    <h2 class="card__title">企業方案</h2>
    <p class="card__content">
      提供進階安全設定與專屬支援。
    </p>
    <footer class="card__footer">
      <a href="#">查看方案</a>
    </footer>
  </article>
</div>
```

外層 Grid 排成三欄。Grid 項目預設會撐滿所在區域，所以同一排的卡片等高，但卡片裡的內容仍不會互相對齊。

```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1.5rem;
}

.card {
  border: 1px solid #d7d7d7;
  border-radius: 0.5rem;
  overflow: hidden;
}

.card > * {
  margin: 0;
  padding: 1rem;
}
```

## Flexbox 可以讓連結區域對齊

先把卡片設成垂直排列的 Flex 容器，再讓中間的內容區塊填滿剩餘空間。

![Flexbox 讓三張卡片的連結區域都貼齊底部，第二張卡片的內容區塊因為標題較長而比較晚開始](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794815420/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/flexbox.png)

```css
.card {
  display: flex;
  flex-direction: column;
}

.card__content {
  flex: 1;
}
```

外層 Grid 先讓卡片等高，`flex: 1` 再填滿各張卡片的剩餘空間，把連結推到底部。不過每張 `.card` 都是獨立的 Flex 容器，只會在自己這張卡片裡分配空間。第二張卡片的標題有兩行，中間內容還是會比另外兩張更晚開始。

如果只想讓連結貼齊底部，Flexbox 已經夠用；如果連標題與內容的起點也要對齊，卡片之間就得共用軌道。

## 一般巢狀 Grid 仍然各算各的

把卡片改成三列 Grid，結果和 Flexbox 很接近。

![一般巢狀 Grid 一樣讓連結區域貼齊底部，但三張卡片的標題高度各自計算](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794815422/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/nested-grid.png)

```css
.card {
  display: grid;
  grid-template-rows: auto 1fr auto;
}
```

三列依序放標題、內容與連結。中間的 `1fr` 撐開後，連結同樣會貼齊底部。

問題和前面的例子一樣：每張 `.card` 都有自己的列軌道。就算 `grid-template-rows` 寫得一模一樣，也只是寫法相同，實際高度還是由各張卡片的內容決定。第二張卡片的標題比較高，下方的格線也會跟著往下，無法和另外兩張連成一線。

## Subgrid 讓卡片共用父層軌道

> [Subgrid（MDN 說明）](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout/Subgrid)

做法是讓每張卡片跨越父層三條列軌道，再用 `subgrid` 沿用這三條軌道。

![使用 Subgrid 後，三張卡片的標題、中間內容與連結區域都落在同一組父層軌道上，虛線標出三條共用軌道的邊界](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794817332/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/subgrid.png)

```css
.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
  gap: 0;
}
```

`grid-row: span 3` 讓卡片跨越三列。設成 `subgrid` 後，標題、內容與連結會依序放進父層的三條列軌道。

`span 3` 不是 Subgrid 的固定寫法，只是因為這張卡片剛好分成三個區塊。如果再加入圖片或標籤，跨越的列數也要跟著增加。

三張卡片的標題現在都在同一條父層軌道上。只要其中一個標題需要兩行，整條軌道就會被撐高；內容與連結也會在各自的共用軌道上對齊。

## 共用軌道的高度怎麼算？

> [CSS Grid Layout Module Level 2（W3C 規範）](https://www.w3.org/TR/css-grid-2/)

這些高度不需要靠 JavaScript 測量。假設三張卡片的標題高度如下：

| 卡片 | 標題需要的高度 |
| --- | ---: |
| A | 30px |
| B | 60px |
| C | 40px |

使用一般巢狀 Grid 時，每張卡片的第一列各自計算，所以高度會是 30px、60px 和 40px。

換成 Subgrid 後，瀏覽器會把三個標題一起納入父層軌道的計算，最後把高度撐到 60px，所以下一列都從相同位置開始。

## 三種做法比較

| 需求 | Flexbox | 一般巢狀 Grid | Subgrid |
| --- | :---: | :---: | :---: |
| 卡片等高（搭配外層 Grid） | 可以 | 可以 | 可以 |
| 連結區域貼齊底部 | 可以 | 可以 | 可以 |
| 不同卡片的標題列對齊 | 不行 | 不行 | 可以 |
| 不同卡片共用父層軌道 | 不行 | 不行 | 可以 |

## 每一排的卡片會各自對齊

同一排的卡片會共用一組父層列軌道，不同排還是各算各的。六張卡片排成三欄時，就算第一排出現兩行標題，也不會撐高第二排。

![六張卡片分成兩排，每一排各自對齊標題、中間內容與連結區域，第一排不影響第二排](https://res.cloudinary.com/dseg0uwc9/image/upload/v1794815426/%E9%83%A8%E8%90%BD%E6%A0%BC%E5%B0%88%E7%94%A8/subgrid/rows.png)

版面改成兩欄時，就會變成每兩張一組；單欄時每排只有一張，也就沒有跨卡片對齊的問題。

## 用 `@supports` 保留 Flexbox

如果專案還要支援不認得 Subgrid 的瀏覽器，可以先用 Flexbox 對齊連結，再用 `@supports` 覆寫：

```css
.card {
  display: flex;
  flex-direction: column;
}

.card__content {
  flex: 1;
}

@supports (grid-template-rows: subgrid) {
  .card {
    display: grid;
    grid-row: span 3;
    grid-template-rows: subgrid;
    gap: 0;
  }
}
```

不支援 Subgrid 時，連結仍會留在卡片底部；支援 Subgrid 時，就能進一步對齊標題、內容與連結。

## 總結

一般巢狀 Grid 會各自計算軌道，即使設定相同，格線也不一定對得上。Subgrid 則直接沿用父層軌道，內容或容器寬度改變時，仍能維持相同的對齊位置。

以卡片為例，如果只要讓連結貼在底部，用 Flexbox 就夠了；如果標題、內容與連結還要跨卡片對齊，再使用 Subgrid。
