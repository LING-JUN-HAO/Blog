### Vue Router 基本使用

路由設定方式，一般可以分成兩種：

- **Hash Mode**：適用於部署簡單專案，特別是靜態網站托管。
    - URL 中包含`#`符號，例如：`example.com/#/about`
    - 瀏覽器不會將`#`後的內容發送到伺服器
    - 切換路由時不會觸發頁面重新載入
    - 無需特殊的伺服器配置
- **HTML 5 Mode** ：適用於部署正式專案。
    - URL 格式無 # 符號，例如：`example.com/about`
    - 提供更好的 SEO 支援
    - 需配置伺服器將所有請求重定向到入口 HTML 檔案（通常在 dist 目錄中）

接下來的說明中，我將使用`Hash Mode`的方式進行說明。

讓我們透過一個範例，快速了解如何在 Vue 中結合 Vue Router 插件來實現顯示不同頁面的功能：

👉 [Vue Router4 基本使用方式(path & component)實作連結](https://stackblitz.com/edit/vitejs-vite-qxtg7m?file=README.md)

![Vue Router 基礎路由導向範例圖](https://res.cloudinary.com/dseg0uwc9/image/upload/v1728637293/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day28%EF%BC%9AVue%20Router%20%E5%AE%98%E6%96%B9%E8%B7%AF%E7%94%B1%E4%BD%BF%E7%94%A8/Vue_Router_%E5%9F%BA%E7%A4%8E%E8%B7%AF%E7%94%B1%E5%B0%8E%E5%90%91_ilpnju.png)

**routers/index.js**：透過`createRouter`方法決定要使用的路由設定方式(history)及路由配對組件(routes)的設定。

```javascript
import { createRouter, createWebHashHistory } from 'vue-router';

const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    {
      // 配對的路徑
      path: '/',
      // 渲染的組件(這邊示範統一先使用異步載入的方式)
      component: () => import('../views/Home.vue'),
    },
    {
      path: '/about',
      component: () => import('../views/About.vue'),
    },
  ],
});

export default router;
```

接著，我們需要使用 Vue Router 提供的全局組件`<RouterView>`來顯示與這些路由配對的組件。`<RouterView>`的作用是指定應用中哪個區域將由 Vue Router 控制，根據當前的路由來顯示對應的組件。這樣，當路由發生變化時，對應的頁面內容會動態顯示在 `<RouterView>`所在的區域。

**App.vue**：

```html
<template>
  <RouterView />
</template>
```

最後，記得在`main.js`入口文件中將 Vue Router 註冊到根組件上，這樣才能在應用中使用路由功能

**main.js**：

```javascript
import { createApp } from 'vue';
import './style.css';
import App from './App.vue';
import router from './router/index.js';

createApp(App).use(router).mount('#app');
```

### Vue Router 路由連結與路由守衛介紹 - RouterLink & Navigation Guards

過去在進行路由導航時，通常會第一時間想到使用`<a href="#">`標籤。然而，在 Vue Router 插件中，路由有自己的一套生命周期管理，因此我們應該使用 Vue Router 提供的 `<RouterLink>`組件來實現導航。這樣可以確保路由切換時不會重新加載頁面，還能充分利用 Vue Router 的路由守衛功能。

**路由守衛常見的全域 hook 功能介紹(全域代表這些 Hook 會應用到每一個路由)**：

- **beforeEach**：最先觸發的守衛。在進入某個路由之前執行，用來檢查使用者是否具備訪問該路由的權限，如果不符合條件，可以阻止使用者導航。。
- **beforeResolve**：在`beforeEach`之後、組件渲染之前觸發。這個 Hook 可以用來進行數據獲取或其他初始化操作，確認一切就緒後才進行路由組件渲染。
- **afterEach**：在導航完成後觸發。通常用於處理一些後續的操作，比如分析數據、記錄導航日誌等。

透過以上範例以及加入路由守衛的修改，讓我們更清楚了解其生命週期發生的順序：

👉 [Vue Router4 基本使用方式搭配路由守衛實作連結](https://stackblitz.com/edit/vitejs-vite-7iuh8x?file=src%2Frouter%2Findex.js)

![RouterLink 與 a 標籤比較範例圖](https://res.cloudinary.com/dseg0uwc9/image/upload/v1728637450/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day28%EF%BC%9AVue%20Router%20%E5%AE%98%E6%96%B9%E8%B7%AF%E7%94%B1%E4%BD%BF%E7%94%A8/RouterLink_%E8%88%87_a_%E6%A8%99%E7%B1%A4%E6%AF%94%E8%BC%83%E7%AF%84%E4%BE%8B%E5%9C%96_jopmbf.png)

**App.Vue**：

```html
<template>
  <nav>
    <ul>
      <li><a href="/about">我是 a 標籤 - About</a></li>
      <li><a href="/">我是 a 標籤 - Home</a></li>
      <li><RouterLink to="/about">我是 RouterLink 組件 - About</RouterLink></li>
      <li><RouterLink to="/">我是 RouterLink 組件 - Home</RouterLink></li>
    </ul>
  </nav>
  <RouterView />
</template>
```

**router/index.js**：

```javascript
// ...略(跟前面路由設置的部分一致，這邊著重說明全局路由守衛)
router.beforeEach((to, from) => {
  console.log('beforeEach');
});

router.beforeResolve((to, from) => {
  console.log('beforeResolve');
});

router.afterEach((to, from, failure) => {
  // 這邊特別將 failure 錯誤訊息印出配合說明  
  console.log('afterEach 發生錯誤', failure);
});
```

**場景一：使用 RouterLink 組件從 Home 切換到 About：**

當我們從`Home 頁面`切換到`About 頁面`，並使用`<RouterLink>`進行導航時，查看路由首頁生命週期觸發順序。

> beforeEach -> beforeResolve -> afterEach 發生錯誤 undefined\*\*

**場景二：使用 RouterLink 組件在 About 頁面重複點擊 About 連結：**

當我們已經在`About 頁面`，再次點擊`<RouterLink>`導航到相同的`About 頁面`時，路由的生命週期只會觸發`afterEach hook`，並顯示以下警告。

> 已在當前頁面了

![Vue Router afterEach hook 警告重複導航到同一頁面](https://res.cloudinary.com/dseg0uwc9/image/upload/v1728637510/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day28%EF%BC%9AVue%20Router%20%E5%AE%98%E6%96%B9%E8%B7%AF%E7%94%B1%E4%BD%BF%E7%94%A8/Vue_Router_afterEach_hook_%E8%AD%A6%E5%91%8A%E9%87%8D%E8%A4%87%E5%B0%8E%E8%88%AA%E5%88%B0%E5%90%8C%E4%B8%80%E9%A0%81%E9%9D%A2_ge2tvk.png)

**場景三：使用 a 標籤在 About 頁面重複點擊 About 連結：**

接著我們使用`<a>`標籤從`Home 頁面`切換到`About 頁面`，查看生命週期觸發順序：

> beforeEach -> beforeResolve -> afterEach 發生錯誤 undefined\*\*

當使用`<a>`標籤進行導航時，瀏覽器會觸發頁面重新載入，這是`<a>`標籤的預設行為。因此，頁面刷新後，所有的生命週期鉤子都會完整觸發，包括`beforeEach`、`beforeResolve`和`afterEach`。

### Vue Router 404 頁面及重導向頁面設定

當用戶輸入錯誤的網址時，通常會有兩種常見的解決方式：

- **404 頁面**：顯示一個專門的頁面，告知用戶當前的 path 無法找到對應的組件來渲染，這是標準的「頁面未找到」處理方式。
- **重導向頁面**：將用戶自動重導向回首頁或其他指定頁面，以確保用戶不會留在無效的路徑上，並提供他們正確的導航選項。

這邊新增一個`PageNotFound.vue`來實做 404 頁面的例子：

在 router/index.js 中，我們可以新增 404 配對規則。這個規則使用 `pathMatch`進行正規化的配對。當其他所有路由規則都未被套用時，這個規則就會被觸發，從而將用戶導向到 404 頁面。

👉 [Vue Router4 基本使用方式(PageNotFound 404 頁面)實作連結](https://stackblitz.com/edit/vitejs-vite-mla1cm?file=src%2Frouter%2Findex.js)

**router/index.js**：

```javascript
{
  path: '/:pathMatch(.*)*',
  component: () => import('../views/PageNotFound.vue'),
}
```

* * *

如果想要改成重導向的方式，可以將配對規則改成如下，改成使用`redirect`屬性進行設定：

### Vue Router 動態取得路由參數與查詢參數

在 Vue 應用中，我們經常需要從 URL 中獲取參數來動態改變頁面內容。Vue Router 提供了兩種主要的參數類型：

- **路由參數(Path Parameter)**：例如`baseurl/id=1`，這種參數是 URL 路徑的一部分，通常用來傳遞必要的動態信息，如資源 ID 或類別。
- **查詢參數(Query Parameter)**：例如`baseurl?id=2&userName=Antonio`，這種參數附加在 URL 路徑之後，通常用來傳遞可選的篩選條件或額外數據。

在介紹動態參數傳遞之前，我們先來了解 Vue Router 提供的`$route`和`$router`兩個全局屬性：

- **$route**：包含當前路由的相關信息，例如路徑、參數、查詢參數等。
- **$router**：提供 Vue Router 的導航方法，例如 push、replace 等，讓我們可以在代碼中動態導航到其他路由。

修改`about`路由配置，使用`:id`動態接收路由參數：

👉 [Vue Router4 基本使用方式(路由參數)實作連結](https://stackblitz.com/edit/vitejs-vite-k2w9eh?file=src%2Frouter%2Findex.js)

**router/index.js**：

```
{
  // id 動態參數(可以用來取得路由參數)
  path: '/about/:id',
  component: () => import('../views/About.vue'),
}
```

### 總結

- **Vue Router 的基本使用**：根據部署方式的不同，`Hash Mode`和 `HTML5 Mode`在瀏覽器顯示和伺服器設定上有所差異。路由的配對規則是由`path`和`component`屬性決定的，並動態渲染對應的組件。
- **使用 RouterLink 組件進行頁面切換**：`<RouterLink>`組件可以避免`<a href>`導致的頁面重新加載問題。全域路由守衛提供了多種應用場景，包括進入路由前的阻擋(beforeEach)、資料預處理(beforeResolve)以及完成導航後的資料分析(afterEach)。
- **404 頁面與重導向設置**：當用戶輸入錯誤的 URL 時，可以透過設置 404 錯誤頁面或自動重導向至特定頁面，從而增強應用的錯誤處理能力，優化用戶體驗。
- **路由動態路由與查詢參數的獲取**：透過在路徑中傳遞路由參數或查詢參數，可以在組件中動態獲取這些數據，從而根據不同參數改變頁面內容或進行資料操作。
