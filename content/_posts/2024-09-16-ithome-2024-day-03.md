### Vite 環境搭建 Vue 專案(適用於正式開發環境)

#### Step 1：安裝 Vue 套件並執行 create-vue

⭐ 需要特別注意，需要事先安裝[Nodejs](https://nodejs.org/en)。若不確定是否已安裝 `Nodejs` 也可以開啟終端機，執行以下指令確認版本。

```bash
node -v
```

如果終端機介面上顯示對應版本號，代表 `Nodejs` 已安裝完成。

![nodejs cmd 確認版本畫面](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624281/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/nodejs_cmd_%E7%A2%BA%E8%AA%8D%E7%89%88%E6%9C%AC%E7%95%AB%E9%9D%A2_c6isbg.png)

Vue 官方提供了一個快速建置 Vue 專案的鷹架工具（Vue project scaffolding tool）。使用以下指令即可創建新專案，並根據中文提示進行配置：

```bash
npm create vue@latest
```

這裡的範例中，選擇默認的配置（按下 Enter）。安裝完成後，你會擁有一個基於 Vite 的 Vue 專案。

![Vue project scaffolding tool 安裝流程 ](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624333/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Vue_project_scaffolding_tool_%E5%AE%89%E8%A3%9D%E6%B5%81%E7%A8%8B_v8r79l.png)

#### Step 2：執行對應指令並啟動開發伺服器

專案建置完成後，您可以使用以下指令來啟動開發伺服器：

```bash
npm run build
```

如圖所示，我們透過`Vite 構建工具`成功啟動了本地開發伺服器。

![Vue 安裝完成啟動 HMR 模式](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624384/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Vue_%E5%AE%89%E8%A3%9D%E5%AE%8C%E6%88%90%E5%95%9F%E5%8B%95_HMR_%E6%A8%A1%E5%BC%8F_jjjbue.png)

在瀏覽器中輸入顯示的網址，即可訪問本地開發環境。

![Vue 初始化畫面](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624429/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Vue_%E5%88%9D%E5%A7%8B%E5%8C%96%E7%95%AB%E9%9D%A2_qcb72n.jpg)

此時我們可能會好奇，`npm run dev`背後到底發生了什麼？我們可以回過頭來查看這個 Vue 專案的資料夾，了解它提供了哪些資訊。

在`package.json`中的`scripts 區塊`，我們可以看到`dev`對應的實際指令：

- dev：啟動熱模塊替換模式 (HMR)，即時更新變動的部分，動態渲染畫面，而不會實際打包檔案。
- build：將專案的所有文件打包成 JavaScript 檔案，因為瀏覽器只能執行 JavaScript。
- preview：預覽打包後的應用，模擬生產環境，確認應用在部署後的運行效果。

```bash
{
  "name": "vue-project",
  "version": "0.0.0",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "vue": "^3.4.29"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.0.5",
    "vite": "^5.4.5"
  }
}
```

#### Step 3：npm run build 打包文檔

當完成開發並準備進行部署時，可以執行以下指令來打包專案：

```bash
npm run build
```

打包完成後，生成的文件將被存放於`dist`資料夾內。可以看到每個檔案的原始大小以及使用`gzip`壓縮後的大小：

![Vite 執行完打包指令](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624494/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Vite_%E5%9F%B7%E8%A1%8C%E5%AE%8C%E6%89%93%E5%8C%85%E6%8C%87%E4%BB%A4_rf0szw.png)

#### Step 4：npm run preview 啟動伺服器讀取打包完後文檔

在執行`npm run preview`前，請先進行`打包 (npm run build)`。打包完成後，`npm run preview`將啟動一個本地伺服器，模擬生產環境的運行效果。

![啟動生產環境模擬伺服器](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624535/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/%E5%95%9F%E5%8B%95%E7%94%9F%E7%94%A2%E7%92%B0%E5%A2%83%E6%A8%A1%E6%93%AC%E4%BC%BA%E6%9C%8D%E5%99%A8_ulu6nc.png)

如圖所示，啟動的模擬伺服器將會從`dist資料夾`中讀取打包後的文件，渲染並模擬生產環境的運行效果。這樣可以方便開發者在本地預覽應用的最終效果，確保在生產環境中能正常運行。

![生產環境模擬伺服器讀取 dist 打包後文檔渲染](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624577/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/%E7%94%9F%E7%94%A2%E7%92%B0%E5%A2%83%E6%A8%A1%E6%93%AC%E4%BC%BA%E6%9C%8D%E5%99%A8%E8%AE%80%E5%8F%96_dist_%E6%89%93%E5%8C%85%E5%BE%8C%E6%96%87%E6%AA%94%E6%B8%B2%E6%9F%93_ptbbp1.jpg)

### 使用 CDN 匯入 Vue HTML（適用於快速測試功能）

在使用 Visual Studio Code 進行開發時，可以快速創建一個 Vue 測試環境。以下是使用 CDN 匯入 Vue 並進行快速測試的步驟：

1. **創建專案資料夾**： 首先，在本地創建一個名為`vue-test`的資料夾，並在其中建立一個`index.html` 文件。
2. **使用 Emmet 語法生成 HTML 結構**： 在`index.html`中，可以使用`Emmet 語法`快速生成基本的 HTML 結構。在 Visual Studio Code 中輸入`!` 並按下 Tab 鍵，即可生成標準的 HTML 結構。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
</html>
```

3. **匯入 Vue UMD 模組**：可以直接在 HTML 中匯入 Vue，而不需要進行任何打包處理。

```html
<!-- 匯入 Vue 的 UMD 模組 -->
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
```

匯入 Vue CDN 後，你可以在全域的`window 物件`上看到 Vue 所定義的屬性和方法。

```javascript
console.log(window)
```

這表示 Vue 已成功載入，開發者可以在 HTML 頁面中直接使用 Vue 所提供的功能和 API。

![Window 全域變數 Vue 屬性](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624633/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Window_%E5%85%A8%E5%9F%9F%E8%AE%8A%E6%95%B8_Vue_%E5%B1%AC%E6%80%A7_mljcht.png)

4. **創建 Vue 應用並掛載至 HTML 元素**：透過 `createApp 方法`來建立 `Vue 應用`，並將其掛載到指定的 HTML 元素。這樣 Vue 就可以接管該元素內的內容並進行數據管理與畫面更新。

![Vue 掛載對應 HTML 標籤(內容將由 Vue 進行管理)](https://res.cloudinary.com/dseg0uwc9/image/upload/v1726624672/2024%20%E9%90%B5%E4%BA%BA%E8%B3%BD/Day%203%EF%BC%9A%E4%BD%BF%E7%94%A8%20Vite%20%E6%90%AD%E5%BB%BA%20Vue%20%E5%B0%88%E6%A1%88/Vue_%E6%8E%9B%E8%BC%89%E5%B0%8D%E6%87%89_HTML_%E6%A8%99%E7%B1%A4_%E5%85%A7%E5%AE%B9%E5%B0%87%E7%94%B1_Vue_%E9%80%B2%E8%A1%8C%E7%AE%A1%E7%90%86_jv47y4.jpg)

## 總結

- **使用 Vite 搭建 Vue 專案**：透過 Vue 的鷹架工具，可以快速搭建完整的 Vue 開發環境（如支援 TypeScript、Router 等）。Vite 提供了預設的指令來啟動開發伺服器，並支援熱模塊替換 (HMR)，讓開發過程更加高效。此外，還能進行專案文件的打包以及啟動生產環境預覽伺服器。
- **使用 CDN 快速搭建 Vue 測試環境**：可以透過引入 Vue 的 UMD CDN 模組，快速在 HTML 中使用 Vue，建立一個輕量的測試環境。這種方式適合用於簡單功能測試，但由於缺乏打包和優化處理，不建議用於正式專案的開發。
